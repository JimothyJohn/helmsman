Edge node

Skipper

You steer, the Skipper runs the machine on the floor. It is a small off-the-shelf board, about $30, that takes power and network from a single Ethernet cable. Plug it into a PoE switch, send it a program from the editor, and it runs.

Download the datasheet (PDF)

Why a small controller

Control where the machine is

  • One cable

    Power and network arrive on the same Ethernet cable. There is no power supply to wire and no cabinet to find room in.

  • Spread it out

    At about $30 a node, each cell or station can have its own controller, so one fault stays in one place.

  • Programmed from anywhere

    Write and check the program in the Helmsman editor in a browser, then send it to the Skipper over the network. Firmware updates travel the same way.

At a glance

What it does

RunsIEC 61131-3 Structured Text programs from the Helmsman editor, on a fixed scan
Talks toRemote I/O over Modbus TCP and EtherNet/IP. See which devices in the device library
Power and networkOne Ethernet port with Power over Ethernet
UpdatesPrograms and firmware over the network
ChangesNeed the node's key; see Security
HardwareAn off-the-shelf ESP32-P4 Ethernet board, about $30

I/O stays out on the machine, in remote I/O blocks. The Skipper runs the logic and talks to them over the network.
