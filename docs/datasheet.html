The soft PLC you program by describing the machine. The agent writes standard IEC 61131-3 Structured Text from your spec, you check it on a live diagram, and an engineer approves it before it runs.

  1. DescribeState the sequence, the interlocks and the alarms the way you would to a colleague. Attach the drawings.
  2. ValidateSee the draft as a live diagram and run it against a simulation of your I/O. Tap any output to see what drives it.
  3. ApproveAn engineer signs off with a PIN. The change goes live between scans; every version is kept and can be rolled back.

Why it holds up

RobustA minimal set of dependencies. Every change passes more than 1,300 automated tests and interoperability tests before it ships.
SimpleOne controller, one service, its own web screen. No cloud, no database server, no stack of microservices.
SafeWritten in a memory-safe language. Changes need an engineer's approval, every change is audited, and the safeguards stay out of your way.
ReliableCompiled, native performance on a fixed scan. A watchdog bounds every scan, and a faulted program stops alone with its outputs safe.

What the agent writes

PROGRAM line
VAR
  s1, s2 : station;
  jam_1 AT %IX0.0 : BOOL;
  alarm AT %QX0.2 : BOOL;
END_VAR
s1(enable := TRUE, jam := jam_1);
s2(enable := TRUE, jam := FALSE);
alarm := s1.alarm OR s2.alarm;
END_PROGRAM
