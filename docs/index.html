tcpethernet

An open-source originator for CIP over TCP/UDP on Ethernet: an explicit-message client and I/O scanner, so an open device can discover, configure, and exchange cyclic I/O with industrial devices that run a conformant adapter stack.

What it is

The scanner side of the wire, in the open.

Most open CIP stacks are adapters: the device end that answers requests. tcpethernet is the other end, the originator that finds devices, reads and writes their attributes over TCP 44818, and opens Class 1 connections that exchange I/O over UDP 2222 at a fixed requested packet interval (RPI).

The workspace also ships the adapter side, used as an in-repo test target and as the base for a soft PLC, so both ends can be exercised without hardware.

Crates

Five crates, one workspace.

tcpethernet

The originator library.

  • Encapsulation header and CPF codecs
  • ListIdentity discovery over UDP
  • Sessions, unconnected explicit messaging, typed errors
  • Forward_Open and the Class 1 I/O scanner

tcpethernet-cli

The tcpethernet binary: discover devices, read attributes, run Class 1 I/O.

tcpethernet-adapter

The target side: sessions, explicit messaging, Forward_Open, Class 1 I/O. The device state machine takes now on every call, so timeouts and production schedules test deterministically.

tcpethernet-iec

IEC 61131-3 Structured Text: a compiler and a scan-cycle interpreter over an %I / %Q / %M process image.

tcpethernet-plc

A soft PLC: one Structured Text program behind the CIP adapter, with a web page for programming it.

Command line

Build it, point it at a device.

cargo build --release

# ListIdentity broadcast
target/release/tcpethernet discover

# Identity object, attributes 1-7
target/release/tcpethernet identity 10.0.0.50

# any attribute, class.instance.attribute, printed as hex
target/release/tcpethernet get 10.0.0.50 0xF5.1.5

# Class 1 exclusive-owner connection
target/release/tcpethernet io 10.0.0.50 --config 151 --out 150 --in 100 \
    --out-len 32 --in-len 32 --rpi 50 --set 0102...

tcpethernet help lists every flag. io binds UDP 2222 locally, because targets send their input data there.

Soft PLC

Structured Text behind the adapter.

tcpethernet-plc runs one IEC 61131-3 program per scan. Each scan copies assembly 150 (what the scanner sends) into %I, runs the program, and copies %Q into assembly 100 (what the scanner receives).

A runtime fault zeroes the outputs and stops the program; the adapter stays on the network so the PLC can still be found.

Ships as a Docker target (docker compose service plc) and a systemd unit for a Raspberry Pi.

PROGRAM blink
VAR count : INT; END_VAR
  count := count + 1;
  %QX0.0 := count MOD 2 = 0;
  %QW1 := INT_TO_WORD(count);
END_PROGRAM

Status

Verified means a capture or a passing test.

Every interop claim is backed by a test in this repo. CI runs a lint and test gate plus an interop suite against the OpENer POSIX sample adapter in Docker.

Develop

A Makefile is the entry point.

make help              # list targets
make lint              # rustfmt check + clippy, warnings denied
make test-all          # everything, locked to Cargo.lock

make opener-up         # OpENer adapter in Docker
make test-interop      # interop suite against it
make opener-down
