# Keyboard

CODESYS's default keys where the browser leaves them alone, nothing on a key the browser owns (F5 and Ctrl R reload, F11 goes full screen). The page keeps the browser's default off these. **Ctrl is ⌘ on a Mac.** Every menu item shows its key.

| key | does | CODESYS command on that key |
|---|---|---|
| Ctrl S | Save | Save Project |
| Ctrl D | Deploy |  |
| Ctrl Enter | Run or stop the simulation |  |
| Shift F8 | Stop the simulation | Stop |
| F10 | Step one scan (stopped) | Step Over |
| Alt F8 | Sign in (box) | Login |
| Ctrl F8 | Sign out (box) | Logout |
| Ctrl Z | Undo in the Structured Text | Undo |
| Ctrl Y | Redo in the Structured Text | Restore |
| Ctrl Shift Z | Redo in the Structured Text |  |
| Ctrl Shift D | Go to definition: the picked block's variable, at its VAR line | Go to Definition |
| Ctrl Shift X | Cross references: every read and write of it lit | Display Cross References |
| Ctrl B | Breakpoint on the picked block (simulation): the scan stops before it; F10 runs the rest of the scan, Ctrl Enter goes on to the next stop |  |
| Ctrl Shift F | Force the picked input: a switch flips, a number's field opens (on a box, an engineer's audited force) |  |
| Ctrl Shift U | Release every force on the box |  |
| Alt 0 | The left pane's Files tab | Devices |
| Alt 1 | The left pane's Code tab (the Structured Text) | POUs |
| Alt 2 | The bottom panel (Trend, Messages) | Modules |
| Alt 3 | The side panel (I/O, Agent) | Messages |
| Alt 4 | The left pane's Devices tab (the I/O map's devices and points) |  |
| Alt ↑ | Up one level in the diagram | |

Reserved, not built yet, on chords rather than function keys: Ctrl ] / Ctrl [ step into / out of an instance, Ctrl F find in the Structured Text with Ctrl G / Ctrl Shift G next / previous, F2 / Shift F2 the Agent.
