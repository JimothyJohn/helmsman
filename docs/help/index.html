Keyboard

Ctrl S save · Ctrl D deploy · Ctrl Enter run or stop the simulation · Shift F8 stop · F10 step one scan · Alt F8 sign in · Ctrl F8 sign out · Ctrl Z / Ctrl Y undo, redo · Ctrl Shift D go to definition · Ctrl Shift X cross references · Alt 0 files · Alt 1 Structured Text · Alt 2 trend · Alt 3 side panel · Alt ↑ up one level. Ctrl is ⌘ on a Mac.
