      Language reference
      
    I[n]  bytes from the scanner (read-only)   Q[n]  bytes to the scanner   M[n] memory
IW[n] QW[n] MW[n]  16-bit little-endian words at byte offset n
X[n].b  bit b (0-7) of a byte               RUN  1 when the scanner is in run
SCAN  scan counter                           MS   milliseconds since start

Q[0] = I[0] + 1            Q[1].0 = I[1].0 && !I[1].1
QW[2] = RUN ? IW[2] * 2 : 0
Q[4..12] = I[4..12]        Q[12..32] = 0      # copy / fill a range
M[0] = M[0] + 1; Q[3] = M[0]                  # ; separates statements

Operators: ?:  ||  &&  |  ^  &  == !=  < <= > >=  << >>  + -  * / %  - ! ~
Numbers: 42  0x2A  0b101010  1_000.  # or // starts a comment.
